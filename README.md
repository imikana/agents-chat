# Команда агентов в Telegram

Два бота в одной группе, которые общаются как живые люди:
- **Разведчик** (Llama через Groq): тёплая, но прямая подруга и «адвокат» Инны. Берёт утренний отчёт Меты из папки Google Диска (и, если нужно, дополняет поиском по вебу).
- **Главный по Инстаграму** (Claude): решает, что снимать, придумывает сценарий, подпись, хештеги.

Как это выглядит в чате: ты просто пишешь, как людям, без команд. Они сами решают, кто отвечает, пишут короткими репликами, зовут друг друга через @, спорят, и когда сошлись, называют общее решение и спрашивают тебя «ок?». Между репликами «печатает…» с паузами. Тебя можно перебивать в любой момент: на новое сообщение они остановят спор и ответят тебе.

Они не выдумывают цифры (охваты, сейвы, проценты): говорят только то, что есть в отчёте. Про алгоритм Инстаграма говорят как о предположении. Если спросишь всерьёз, люди ли они, честно скажут, что ИИ-агенты. Ничего не публикуется в Инстаграм без твоего «ок».

## Запуск (порядок важен: сначала чат, потом Google)

### 1. Боты
В @BotFather у обоих ботов: `/setprivacy` → выбрать бота → **Disable**. Токены сохрани у себя, в чат и в GitHub их не отправляй.

### 2. GitHub
Создай приватный репозиторий `agents-chat` и загрузи туда `main.py`, `requirements.txt`, `README.md` (Add file → Upload files). Проверь, что у Render есть доступ к этому репозиторию (GitHub → Settings → Applications → Render → Repository access).

### 3. Render
Сервис можно создать двумя способами, цена одинаковая ($7 в месяц за самый дешёвый платный тариф):
- **Web Service** (его может создать Claude через подключённый Render): Python, Build `pip install -r requirements.txt`, Start `python main.py`, тариф платный (бесплатный засыпает, и боты замолчат).
- **Background Worker** (создаёшь сама в дашборде): те же команды.

Программа сама понимает, какой это тип сервиса.

Дальше в дашборде сервиса, раздел **Environment**, впиши ключи сама:
`TG_TOKEN_SCOUT`, `TG_TOKEN_IG`, `ANTHROPIC_API_KEY`, `GROQ_API_KEY`.

### 4. Два числа
Когда сервис запустится, напиши в группе `/id`. Бот ответит двумя числами: `chat_id` группы и твой `user_id`. Впиши их в Environment как `GROUP_CHAT_ID` и `OWNER_ID` (сервис перезапустится). Теперь можно писать в чат: они ответят, но про тренды скажут честно, что отчёта пока нет.

### 5. Папка с отчётами Меты (один раз, минут 15)
1. Открой console.cloud.google.com, создай проект.
2. Включи там «Google Drive API» (поиск по названию).
3. «IAM и администрирование» → «Сервисные аккаунты» → создай аккаунт (название любое).
4. Открой созданный аккаунт → вкладка «Ключи» → «Добавить ключ» → JSON. Скачается файл.
5. Открой этот файл, найди `client_email` (адрес вида `...@...iam.gserviceaccount.com`). Дай этому адресу доступ **«Читатель»** к папке «Тренды Reels»: «Поделиться» на папке.
6. Весь текст файла JSON вставь в Environment как `GOOGLE_SERVICE_ACCOUNT_JSON`. Этот ключ как пароль: никому не отправляй и в GitHub не клади.
7. Добавь `DRIVE_FOLDER_ID` (кусок адреса папки после `/folders/`).

В названии файла отчёта должны быть слова «Тренды Reels» (так бот находит нужные файлы).

### Необязательные переменные
- `TAVILY_API_KEY`: поиск по вебу как дополнение к отчёту Меты
- `DAILY_POST_TIME`: например `07:30`, тогда они сами обсудят отчёт каждое утро (Мета собирает в 07:00, так что есть запас)
- `DAILY_LIMIT`: сколько реплик агентов в сутки, по умолчанию 40
- `MAX_TURNS`: сколько реплик максимум на одно твоё сообщение, по умолчанию 6
- `HUMAN_PAUSE=0`: выключить паузы «печатает…»
- `DRIVE_TITLE_PREFIX`, `TZ_OFFSET_HOURS` (по умолчанию 5, Казахстан)

## Как с ними говорить

- Просто пиши в чат. Диспетчер выберет, кто отвечает первым.
- `@имя_бота вопрос` или ответ (reply) на сообщение бота: отвечает этот агент.
- `/trends` (или `/trends сон малыша`): позвать их обсуждать свежий отчёт.
- `/help`: подсказка.

## Расходы

Каждая реплика агента это один платный вызов нейросети (плюс мелкий вызов диспетчера на свободные сообщения). Живое общение значит больше реплик, поэтому предохранители: не больше `MAX_TURNS` реплик на одно твоё сообщение и не больше `DAILY_LIMIT` реплик в сутки. На последней реплике спора агенты обязаны подвести итог и спросить тебя. Если за сутки лимит кончится, бот напишет об этом.

Если утром нового отчёта в папке нет, автопост просто напишет об этом одной строкой и ничего не потратит.

## Важно

- Писать должна только ты (`OWNER_ID`) и только в своей группе: чужих бот не слушает.
- Если после смены Group Privacy бот всё равно молчит, удали его из группы и добавь заново.
- Названия моделей (`CLAUDE_MODEL`, `GROQ_MODEL`) можно менять переменными, если какая-то устареет.

## Третий агент: Аналитик (необязательно)

Аналитик читает статистику Инстаграма. ChatGPT берёт её из Metricool и сохраняет отчётом (Google Документ, в названии «Статистика Reels») в папку «Статистика» на Диске. Мозг Аналитика: модель OpenAI.

Чтобы включить, добавь в Render → Environment:
- `TG_TOKEN_STATS`: токен третьего бота из @BotFather (у него тоже Group Privacy → Disable, бот добавлен в группу)
- `OPENAI_API_KEY`: ключ с platform.openai.com (отдельно от подписки ChatGPT, нужен баланс)
- `STATS_FOLDER_ID`: id папки «Статистика» (кусок адреса после `/folders/`)
- `OPENAI_MODEL`: необязательно, по умолчанию `gpt-5-mini`

Папку «Статистика» нужно дать сервисному аккаунту (адрес `...@...iam.gserviceaccount.com`) с ролью «Читатель», так же как «Тренды Reels».

Команда `/stats`: Аналитик расскажет, как зашли последние рилсы. Свободные вопросы про цифры ему передаёт диспетчер.

## Офис (мини-приложение в Telegram)

Файл `office.html` — мини-приложение «Офис»: агенты ходят, пьют кофе, болтают, а кошка спит на подушке. Сервис сам отдаёт его по адресу `/office`, а данные берёт из `/state` (только для владельца).

Кнопка «Офис» ставится сама в личке с ботом «Главный» (один раз нажми Start). Адрес берётся из `PUBLIC_URL` или `RENDER_EXTERNAL_URL`.
